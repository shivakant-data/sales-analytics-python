# 📊 Sales Analytics with Python

## 📌 Project Overview

This project analyzes sales transaction data using Python and Pandas to understand sales performance, profitability, product performance, customer performance, city performance, and monthly trends.

The project follows a practical Data Analyst workflow:

**Raw Data → Data Cleaning → Analysis → KPIs → Visualization → Business Insights**

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains sales transactions with information including:

- Order ID
- Order Date
- Customer
- City
- Product
- Category
- Quantity
- Sales
- Profit
- Payment Method

---

## 🔍 Analysis Performed

### 1. Data Cleaning

- Checked missing values
- Checked duplicate records
- Standardized text values
- Converted dates to proper datetime format
- Converted numerical columns to appropriate data types
- Validated the dataset before analysis

### 2. Sales KPIs

| KPI | Result |
|---|---:|
| Total Sales | ₹867,500 |
| Total Profit | ₹129,800 |
| Average Sales per Order | ₹28,916.67 |
| Average Profit per Order | ₹4,326.67 |
| Median Sales | ₹27,000 |
| Overall Profit Margin | 14.96% |

### 3. Product Analysis

Analyzed:

- Sales by product
- Profit by product
- Quantity sold
- Number of orders
- Profit margin

### 4. City Analysis

Compared sales, profit, quantity, orders, and profit margin across cities.

### 5. Monthly Analysis

Analyzed sales and profit trends across:

- January
- February
- March

---

## 📌 Key Business Insights

- 💰 Total sales were **₹867,500**, with total profit of **₹129,800** and an overall profit margin of **14.96%**.
- 💻 **Laptop** generated the highest sales at **₹412,000** and the highest product profit at **₹56,600**.
- ⌨️ **Keyboard, Headphones, and Mouse** had the highest product-level profit margin at **20%**.
- 🏙️ **Bangalore** generated the highest city-level sales at **₹325,000**.
- 📦 **Delhi** recorded the highest number of orders with **9 orders**.
- 📈 **March** had the highest monthly sales at **₹304,500** and profit of **₹45,800**.
- 📊 **February** had the highest monthly profit margin at **15.76%**.
- 👤 **Neha** generated the highest customer sales at **₹137,000** and had an AOV of **₹45,666.67**.
- 🏆 The highest-value order was **Order 2004**, with sales of **₹62,000**.
