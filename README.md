# 📊 Sales Analytics with Python

## 📌 Project Overview

This project analyzes sales transaction data using Python and Pandas to understand sales performance, profitability, product performance, city performance, payment methods, and monthly trends.

The project follows a practical Data Analyst workflow:

**Raw Data → Data Cleaning → Analysis → KPIs → Visualization → Business Insights**

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains sales transactions with information including:

- Order ID
- Order Date
- Customer
- City
- Product
- Category
- Quantity
- Sales
- Profit
- Payment Method

---

## 🔍 Analysis Performed

### 1. Data Cleaning

- Checked missing values
- Checked duplicate records
- Standardized text values
- Converted dates to proper datetime format
- Converted numerical columns to appropriate data types
- Validated the dataset before analysis

### 2. Sales KPIs

| KPI | Result |
|---|---:|
| Total Sales | ₹867,500 |
| Total Profit | ₹129,800 |
| Average Sales per Order | ₹28,916.67 |
| Average Profit per Order | ₹4,326.67 |
| Median Sales | ₹27,000 |
| Overall Profit Margin | 14.96% |

### 3. Product Analysis

Analyzed:

- Sales by product
- Profit by product
- Quantity sold
- Number of orders
- Profit margin

### 4. City Analysis

Compared sales, profit, quantity, orders, and profit margin across cities.

### 5. Monthly Analysis

Analyzed sales and profit trends across:

- January
- February
- March

### 6. Payment Method Analysis

Compared transaction performance across different payment methods.

---

## 💡 Key Business Insights

- Total sales generated were **₹867,500**.
- Total profit was **₹129,800**.
- Overall profit margin was approximately **14.96%**.
- Laptop generated the highest product sales.
- Product-level margins varied considerably across products.
- Monthly sales and profit were compared to identify performance trends.
- City-level analysis was used to understand differences in sales and profitability.
- Payment-method analysis helped compare transaction performance.
